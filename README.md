# The Day in World News

A deterministic, illustrated 1024 × 1024 newspaper front page for Wednesday 18 November 2026. Generated with Python, Pillow, and DejaVu fonts, with thirteen original vector-style news vignettes, a seven-region world map, and all 44 stories presented in a compact editorial layout.

Run `python3 gen.py` to reproduce `entry.png`. The make.fun runner uses `main.ts` to copy the finished entry into `MAKEFUN_OUTPUT_DIR`.
